## Findings

### Minor

1. **`/index.html` returns 307, not 308.** `curl -sI https://capeindex.com/index.html` -> `HTTP/1.1 307 Temporary Redirect · Location: /`. Wrangler assets does this by default. A canonical URL should redirect permanently so crawlers and social scrapers cache it. Fix: set `redirect_asset_paths` on the assets binding, or add a `_redirects` line `/index.html / 308`.

2. **`http://www.capeindex.com/` takes two hops to reach the canonical URL.** `curl -sL -o/dev/null -w "%{num_redirects}"` returns 2 (http+www -> https+www -> https+apex). Cloudflare's Always Use HTTPS keeps the host, then the zone's www->apex rule fires. A single Redirect Rule at the edge (`http://www.capeindex.com/*` -> `https://capeindex.com/$1`, 301) collapses it to one. Cost is a browser round trip on plain-HTTP www links only.

3. **404 responses lack a charset in `Content-Type`.** `curl -sI https://capeindex.com/404-test-nope` reports `Content-Type: text/html` (no `; charset=utf-8`). The 404 body itself declares `<meta charset="utf-8">` (`build-sidecars.mjs:55`), so browsers render it right, but the header is inconsistent with the `/` and `/index.html` overrides. Fix: add `/404.html\n  Content-Type: text/html; charset=utf-8` to the `_headers` list in `build-sidecars.mjs:93`.

4. **`robots.txt` and `sitemap.xml` revalidate on every request.** Both come back `Cache-Control: public, max-age=0, must-revalidate` (the default). Crawlers hit these often and the payload is 1,836 B and ~230 B; a `max-age=3600` at the edge would cut origin traffic without hiding a change longer than the weekly rebuild cadence. Fix: add `/robots.txt` and `/sitemap.xml` entries with `Cache-Control: public, max-age=3600` in `build-sidecars.mjs`.

5. **`web-cast.json` inlines 67 KB of roster payload, mostly non-latin characters and film title repetition.** `<script id="cast-data">` measures 67,407 B; `<script id="data">` is 30,973 B. Roughly 30% of `cast-data` is `actorsByFilm` maps whose keys duplicate film titles already in `data`. A single `filmId` integer per entry, keyed to `data.films[i].t` at load, would drop 10 to 15 KB pre-compression. Not urgent (brotli collapses much of it), but this is the last chart-agnostic slim left.

## Checked clean

- Every `innerHTML` sink in `src/index.html` (43 of them, listed on the left rail via `grep -nE "innerHTML|insertAdjacentHTML"`). Data from `web.json` and `web-cast.json` is escaped in each sink: `esc(f.t)` in `filmTip` (`src/index.html:1742`), scatter labels (`:2272`), roster labels (`:3055`, `:3097`, `:3153`), footprint labels (`:3259`, `:3268`), ensemble hover names (`:3197`, `:3199`), character tips (`:3030`, `:3115`, `:3116`, `:3230`); `safeCell` guards every `fillTable` cell (`:2525`, whitelists the `uchip` and `inrelease` fragments then requires no other markup). `filmTitlesInOrder` (`:3024`) returns raw titles into `fillTable`, but they route through `safeCell` in the same call. Nothing interpolates a data field into an event-handler attribute.
- Hash router (`goToHash` at `:4064`) never writes DOM based on the hash; it looks up an element by id, calls `setTab`, and `scrollIntoView`. `location.hash` is not URL-decoded, so a crafted hash cannot introduce markup or reach an unintended id.
- `localStorage` reads are guarded (`:31` pre-paint, `:3806`, `:3852`, `:3857`) and the theme value is checked against `"dark"|"light"` before use.
- CSP round-trips cleanly: `default-src 'none'`, `script-src` = two exact sha256s plus the Insights beacon origin, `connect-src` = `cloudflareinsights.com`, `img-src 'self' data:`, `font-src 'self'`, `style-src 'unsafe-inline'`, `base-uri 'none'`, `form-action 'none'`, `frame-ancestors 'none'`. Nothing the page fetches or executes falls outside the policy. The two `<script type="application/json">` data blocks are correctly excluded from the hash list (they never execute).
- `JSON.parse` of the two data blocks (`:1487`, `:1489`) is safe because `scripts/build.mjs:16` rewrites `</` to `<\/` before splicing, keeping the closing script tag out of the JSON string content.
- Listeners are not leaking: `resetScrollHints` (`:2476`) disconnects observers on every `renderFullTable`, `THAW_ON` handlers detach themselves on the settle callback (`:3989`), and `SCROLL_HINTS` is reset in place. `WeakMap TIP_IDS` does not root the elements. The three window `resize` listeners each queue via rAF or a 200 ms setTimeout, so an address-bar scroll on mobile does not thrash.
- Sidecars: robots.txt correct and parseable, sitemap.xml valid with `<lastmod>` = data generation date, `reconcilers.zip` served as `application/zip` with a revalidate cache (correct, contents may change), the zip is byte-stable across identical builds via fixed DOS timestamp in `build-bundle.mjs:27`.
- No third-party request other than the Cloudflare Insights beacon at `static.cloudflareinsights.com/beacon.min.js`. Fonts are self-hosted from `/fonts/` with `font-display: swap` and three preload hints. No Google Fonts, no analytics beyond the cookieless beacon, no external images.
